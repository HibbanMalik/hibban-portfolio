# Hibban Malik Portfolio

Personal developer portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Run the project

Open this folder in VS Code, then run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Where to make changes

- `app/page.tsx` - page content, links, projects, and skills
- `app/globals.css` - colors, spacing, layout, and responsive styles
- `app/layout.tsx` - browser title and description
- `public/` - résumé and favicon

## Useful commands

```bash
npm run dev     # Start the local site
npm run build   # Check the production build
npm run lint    # Check for code issues
```
